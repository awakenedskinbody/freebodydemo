# freebodydemo.com

One-page site where people book a free Invisa-RED demo. The domain goes on the street signs.

- Hosting: Netlify project `demo-awakened-skin-body`, auto-deploys from `main`.
- Booking: Cal.com, embedded inline. The event links are at the top of the script in `index.html` (`CAL_LINKS`), one for English and one for Spanish.
- Languages: English and Spanish on the same page. The page opens in Spanish when the phone is set to Spanish, or with `?lang=es` in the link.
- Tracking: GA4 `G-N31V27CTCY`, Google Ads `AW-18174427039`, Meta Pixel `2112349302961771`. Events: `cta_click`, `language_switch`, `demo_booked` (GA4); `Contact` and `Schedule` (Meta).
- Copy rules: Invisa-RED copy talks about inches off the waist, hips and thighs only. "FDA-cleared laser" stays in its own sentence. The Florida s. 456.062 statement stays in the footer because the page advertises a free service.
